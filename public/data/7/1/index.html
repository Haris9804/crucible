Phase 1- Checking for system virtualization

Incomplete

⚠ Checking for system Virtulization is Important

System Pre-requsts

Windows 10/11

4 Gb RAM

Step 1: Open Task Manager

Press Ctrl+Shift+Esc (Task Manager)
Click on Performance
Click on CPU section

Step 2: Check system Virtulization

Scroll to the bottom of the Task Manager
Check for: "Virtualization: Enabled"
If enabled, the Phase is completed
Skip Step 3 and goto next Phase

Step 3: If not enabled

Boot laptop in BIOS settings
Go to Configuration
Turn on Virtualization by "Enabling" it
Reboot the system

Phase 2- Installing VMware or VirtualBox (Hypervisor Software)

Incomplete

⚠ Installing a Hypervisor is required to run virtual machines

Select Hypervisor Software

VMware Workstation Pro Installation Guide (Recommended)

Step 1: Create Broadcom Account

Go to Broadcom registration page
Create a new account
Login to Broadcom portal

Step 2: Download VMware Workstation Pro

Search for "VMware Workstation Pro"
Click on the search result
Select Windows version 17.0
Select version 17.5.x or 17.6
Click on "Terms of Use"
Check the agreement box
Click Download
Provide additional details if requested

Step 3: Install VMware

Double click the downloaded installer
Click Next
Check "I Agree to the license agreement"
Click Next on all steps
Click Install
Wait for installation to complete
VMware will now be ready to use

Phase 4 - Setting Up Kali Linux on Hypervisor

Incomplete

⚠ This phase covers adding Kali Linux to VMware Workstation Pro or VirtualBox

Select Hypervisor

Add Kali on VMware Workstation Pro

Step 1: Open VMware

Launch VMware Workstation Pro

Step 2: Create a New Virtual Machine

Click on "Create a new virtual machine"
Select "Typical" and click Next
Select "Installer disc image file (iso)" option
Browse to the folder containing the downloaded Kali Linux .iso file
Click Next after selecting the ISO

Step 3: Configure Guest OS

Select Linux as Guest operating system
In Version, select "Debian 12.x 64-bit"
Click Next

Step 4: Name and Location

Provide Virtual Machine name: KALI
Leave location as default and click Next

Step 5: Configure Disk

Provide disc size (20-25GB minimum recommended)
Select only "Split virtual disc into multiple files" and click Next

Step 6: Customize Hardware

Click on "Customize Hardware" button
Memory: 2-4GB (Minimum 2GB)
Processors: 1 Processor + 3 cores
Network: Select "Bridged adapter" and check "Replicate physical network connection state"
Leave rest as default and click Finish
Kali Linux is now added in VMware

Add Kali on VirtualBox

Step 1: Create New Virtual Machine

Click on "New" button/icon
Enter Name: Kali Linux (or any name)
Folder: default location
ISO image: select downloaded Kali .iso
Type: Linux, Subtype: Debian, Version: Debian (64-bit)

Step 2: Configure Hardware

Base Memory: recommended half of total RAM (minimum 2048-4096MB)
Processors: 2 or 4

Step 3: Configure Hard Disk

Select "Create a Virtual Hard Disk Now"
Hard Disk Location: default
Allocate size: 20-40GB
Click Finish

Step 4: Extra Settings

Click on Kali Linux machine → Settings
General → Advanced: Set "Shared Clipboard" and "Drag n Drop" to Bidirectional
System → Acceleration: Ensure Hardware Virtualization is enabled
Display → Screen: Max Video memory, Graphics Controller set to VMSVGA
Storage → Controller IDE → Select Empty → Click disc icon → Choose a disc file → Select Kali .iso
Network → Enable Network Adapter → Attached to: Bridged Adapter
Kali Linux is now added in VirtualBox

Phase 5 - Final Kali Linux Setup

Incomplete

⚠ This phase completes the Kali Linux installation inside the virtual machine

Basic Setup

Click on "Power on this virtual machine"
Use keyboard in the Kali setup
Select "Graphical Install" → Press Enter
Select your location: "United States" (default) or "India" → Click Continue
Configure the keyboard: American English (default) → Click Continue
Hostname: kali (default)
Domain name: Leave blank → Click Continue
Full name for your user: cybergeek → Click Continue
Username for account: cybergeek (all lowercase) → Click Continue
Password: Enter your password → Click Continue
Configure the clock: "Eastern" option → Click Continue

Disk Partition

Partition disk: Select "Guided – Use entire disk" → Click Continue
Select disk: Default "SCSI133 (0,0,0) (sda) – …" → Click Continue
Select partition: "All files in one partition (recommended for new users)" → Click Continue
Select "Finish partitioning and write changes to disk" → Click Continue
Write changes to disk: Select "Yes" → Click Continue
Wait for installation process to complete (may take a while)

Display and GRUB

Default display manager: Select "gdm3" → Click Continue
Install GRUB boot loader: Select "Yes" → Click Continue
Device for boot loader: Select "/dev/sda" → Click Continue
Choose to reboot → Click Continue
Kali Linux will start
Provide username and password → Welcome to Kali Linux!
