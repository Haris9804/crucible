FTP Service Exploitation

Incomplete

⚠ Practice only in authorized lab environments.

Reconnaissance Steps

Run Nmap scan on target IP address.
Identify if FTP service (Port 21) is open.
Use service detection (-sV) to view FTP version.
Search online if that FTP version has known vulnerabilities.

Option 1: Using Metasploit

Start Metasploit Framework.
Search for FTP related exploit modules.
Select appropriate exploit.
Configure required options (RHOSTS, etc).
Run the exploit.

Metasploit Commands

msfconsole
search ftp

Option 2: Direct FTP Connection

If username/password is known, attempt login.
Connect to FTP service manually.
Check accessible directories and files.

FTP Connection Command

ftp <target-ip>
